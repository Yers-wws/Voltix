# Voltix TechStore - REST API Backend

Бэкенд для проекта интернет-магазина электроники **Voltix TechStore**, разработанный на **Python** и **FastAPI** в соответствии с требованиями и лекционными материалами курса (Week 9–11).

---

## Архитектура проекта

Проект организован по многоуровневой архитектуре с разделением ответственности:

```text
backend/
├── main.py                  # Точка входа, инициализация FastAPI, CORS middleware, подключение роутеров
├── config.py                # Конфигурация, бизнес-константы (скидки, доставка)
├── requirements.txt         # Зависимости проекта
├── models/
│   ├── __init__.py
│   └── schemas.py           # Pydantic-схемы для строгой валидации входящих и исходящих данных
├── routers/
│   ├── __init__.py
│   ├── products.py          # REST-эндпоинты каталога товаров и отзывов (/api/products)
│   ├── orders.py            # REST-эндпоинты оформления и отмены заказов (/api/orders)
│   └── promos.py            # REST-эндпоинты проверки промокодов (/api/promos)
├── services/
│   ├── __init__.py
│   ├── product_service.py   # Бизнес-логика каталога, фильтрации, пересчета рейтинга
│   ├── order_service.py     # Бизнес-логика резервирования стока, применения скидок, доставки
│   └── promo_service.py     # Бизнес-логика промокодов
├── storage/
│   ├── __init__.py
│   └── db.py                # Потокобезопасное In-Memory хранилище с реалистичными начальными данными
└── tests/
    ├── __init__.py
    └── test_api.py          # Автоматические тесты (pytest + TestClient)
```

## Реализованные рабочие сценарии (Core Workflows)

### 1. Каталог товаров и складской учет (Product Catalog & Inventory)
* **Просмотр и фильтрация:** фильтрация по категории (`category`), бренду (`brand`), диапазону цен (`min_price`, `max_price`), наличию на складе (`in_stock`), поиск (`search`) и сортировка (`sort_by`).
* **Детальный просмотр:** получение карточки товара с авто-расчетом цены со скидкой (`sale_price`) и динамическим средним рейтингом.
* **Управление складом (CRUD):** создание новых товаров, частичное обновление характеристик и остатков (`PATCH`), удаление (`DELETE` с кодом `204 No Content`).

### 2. Оформление заказа и списание со склада (Order Checkout & Stock Reservation)
* **Взаимодействие связанных ресурсов:** связка *Products $\leftrightarrow$ Orders $\leftrightarrow$ Promos*.
* **Валидация:**
  * Проверка валидности email через regex.
  * Проверка наличия каждого товара в каталоге (возврат `404 Not Found`).
  * Проверка доступного остатка на складе (`stock`). Если запрошено больше, чем доступно, заказ отклоняется с кодом `400 Bad Request` («Insufficient stock...»).
* **Бизнес-логика:**
  * Применение промокода (`TECH10` — скидка 10%). Невалидный код отклоняется с `400 Bad Request`.
  * Расчет доставки: при сумме заказа от \$500 доставка **бесплатная**, иначе \$15.
  * **Атомарное списание стока:** количество заказанных товаров сразу уменьшается на складе.
* **Отмена заказа (`POST /api/orders/{id}/cancel`):**
  * Заказ переводится в статус `cancelled`.
  * **Автоматический возврат товаров на склад** (сток восстанавливается).
  * Повторная отмена отклоняется с `400 Bad Request`.

### 3. Отзывы и динамический рейтинг (Reviews & Rating Recalculation)
* Клиенты могут оставлять отзывы с оценкой от 1 до 5 звезд.
* При отправке отзыва бэкенд автоматически пересчитывает средний рейтинг товара (`rating`) и увеличивает счетчик отзывов (`reviews_count`).

### 4. Промокоды и акции (Promotions)
* Эндпоинт `/api/promos/validate` для валидации скидочного купона до завершения покупки.

## REST API спецификация

| Метод | Эндпоинт | Статус | Описание |
| :--- | :--- | :--- | :--- |
| **GET** | `/health` | `200 OK` | Проверка работоспособности сервиса |
| **GET** | `/api/categories` | `200 OK` | Список поддерживаемых категорий магазина |
| **GET** | `/api/products` | `200 OK` | Список товаров с фильтрами, поиском и сортировкой |
| **GET** | `/api/products/{id}` | `200 OK` / `404` | Детальная информация о товаре |
| **POST** | `/api/products` | `201 Created` / `422` | Добавление нового товара |
| **PATCH**| `/api/products/{id}` | `200 OK` / `404` | Частичное обновление данных/остатка |
| **DELETE**|`/api/products/{id}` | `204 No Content` / `404`| Удаление товара из каталога |
| **GET** | `/api/products/{id}/reviews`| `200 OK` / `404` | Список отзывов по товару |
| **POST** | `/api/products/{id}/reviews`| `201 Created` / `422`| Добавление отзыва (пересчитывает рейтинг) |
| **GET** | `/api/orders` | `200 OK` | История всех оформленных заказов |
| **POST** | `/api/orders` | `201 Created` / `400` / `404` / `422` | Оформление заказа со списанием стока |
| **GET** | `/api/orders/{id}` | `200 OK` / `404` | Получение информации о заказе |
| **POST** | `/api/orders/{id}/cancel` | `200 OK` / `400` / `404` | Отмена заказа с возвратом стока |
| **POST** | `/api/promos/validate` | `200 OK` / `400` | Валидация промокода |
| **GET** | `/api/promos` | `200 OK` | Список действующих акций |

## Запуск приложения

### 1. Активация виртуального окружения
В терминале PowerShell из папки `backend`:
```powershell
.\.venv\Scripts\Activate.ps1
```

### 2. Запуск сервера разработки
```powershell
python main.py
# или
uvicorn main:app --reload --port 8000
```
Сервер будет доступен по адресу: [http://127.0.0.1:8000](http://127.0.0.1:8000)

### 3. Интерактивная документация Swagger UI
Откройте в браузере:
* **Swagger UI:** [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
* **ReDoc:** [http://127.0.0.1:8000/redoc](http://127.0.0.1:8000/redoc)

## Запуск автоматических тестов

Для запуска всех тестов с подробным выводом:
```powershell
.\.venv\Scripts\python.exe -m pytest tests -v
```
Все тесты проверяют как успешные сценарии, так и обработку ошибок (`400`, `404`, `422`, `204`).
